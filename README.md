# Tanmay Sah Portfolio

GitHub Pages-ready static portfolio.

## IMPORTANT: GitHub upload structure

After extracting this ZIP, upload the CONTENTS of this folder to the ROOT of your GitHub repository.

The repository root must look like:

```text
Tanmay-Portfolio/
├── index.html
├── style.css
├── script.js
├── .nojekyll
├── README.md
└── assets/
    ├── favicon.svg
    └── Tanmay-Sah-Resume.pdf
```

Do NOT upload the outer folder itself if using GitHub's web uploader.

## GitHub Pages

Repository:
`Tanmay4777/Tanmay-Portfolio`

Settings → Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

The `index.html` file must be directly in the selected publishing source root.
